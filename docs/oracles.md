# What compares what

Every artefact this emitter produces, and what would catch it disagreeing with the thing it has to
agree with.

The two defects that reached a consumer were the same shape: two artefacts generated by one program,
compared by nothing. This page exists so that a pair with no comparator is visible before a consumer
finds it, rather than after.

Each row was checked by planting a defect and confirming the named arm goes red.

## Known gaps

- **A metadata-carrying model used as both a payload root and a nested body** loses its header property
  where the document keeps it. `isPayloadProperty` takes an `ignoreMetadataAnnotations` argument that
  openapi3 threads as emitter context and this does not pass. It raises `metadata-ignored` from
  `@typespec/http`, which fires zero times across the corpus.
- **`format` is compared by neither axis**, deliberately: it is an annotation rather than an
  assertion, and a class assertion in `vocabulary.test.ts` refuses any format-derived Zod call, so
  enabling one breaks a test rather than moving a number.
- **4 negotiated response bodies** cannot be attributed to a single arm, and **4 reduce to no readable
  kind** on one side. Both are pinned counts rather than floors.

## How a new pair gets a comparator

An artefact added here without a row above is a pair nobody is comparing. The rule that produced this
page: for each thing the emitter writes, name the thing it must agree with, then plant a defect and
confirm something goes red. If nothing does, that is the next defect, and a consumer will find it.
